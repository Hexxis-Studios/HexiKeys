# Security and privacy

HexiKeys is an early Windows preview, not an independently audited password manager. Test with disposable entries before relying on it for important credentials. An unlocked vault necessarily exposes plaintext to the application process; it cannot protect against a compromised device.

Never attach real vaults, backups, passwords, API keys, pairing descriptors, screenshots of secrets, or recovery phrases to public issues. Encryption does not make a personal vault appropriate to publish.

Report suspected vulnerabilities privately to hexxis.cmd@proton.me, without including real credentials. Include reproduction steps using synthetic entries. This contact does not imply a guaranteed response time or a bug-bounty program.

The public repository and release contain application code, artwork, synthetic tests and runtime dependencies, not personal vaults or pairing credentials.
